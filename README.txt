نسخة تجريبية للواجهة فقط - بدون Raspberry Pi وبدون حساس وبدون كاميرات حقيقية.

طريقة الاستخدام:
1) فك الضغط.
2) افتح index.html.
3) اسم المستخدم: admin
4) كلمة المرور: 123456
5) اختر الموقع.
6) سترى 12 مخزنًا، لكل مخزن كاميرتان تجريبيتان وحرارة ورطوبة تتغير تلقائيًا.

يمكن رفع الملفات كما هي على GitHub Pages أو Vercel.

لاحقًا يتم استبدال القيم التجريبية بقراءة حساس RS485 عبر Raspberry Pi،
واستبدال البث التجريبي بروابط الكاميرات الحقيقية.


=== البث الحقيقي - MediaMTX ===
تم ربط كاميرا 1 في مخزن 1 / تكريت بالبث:
http://127.0.0.1:8889/camera1/

المتطلبات:
1) تشغيل MediaMTX على نفس الكمبيوتر.
2) إعداد camera1 في mediamtx.yml ليقرأ RTSP من الكاميرا.
3) فتح المشروع على نفس الكمبيوتر.

ملاحظة أمنية: لا يتم تخزين اسم المستخدم أو كلمة مرور الكاميرا داخل ملفات HTML/JavaScript. تبقى بيانات RTSP داخل mediamtx.yml فقط.
